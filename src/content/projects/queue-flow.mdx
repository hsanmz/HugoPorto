## Ringkas

Aplikasi manajemen antrian yang mengelompokkan antrian per periode. Satu periode punya antriannya sendiri, dan petugas mengubahnya dari satu layar. Kode tidak ditautkan dari halaman ini, jadi isinya adalah desain sistem.

> Catatan: dokumen ini masih bertanda **Perlu dilengkapi**. Bagian yang kosong akan diisi setelah detail teknis proyek tersedia, dan tidak diisi dengan dugaan.

## Konteks dan batasan

Antrian berjalan per periode, misalnya per hari atau per sesi layanan. Tiap periode perlu daftar sendiri, dan status tiap nomor berubah sepanjang hari. Untuk alat internal seperti ini, kebutuhan backend-nya tipis: baca, tulis, dan realtime.

## Arsitektur

Frontend Vite dan React di atas Supabase. Supabase menyediakan database dan API, jadi tidak ada service backend terpisah. Build akhirnya statis dan disajikan dari Vercel.

```text
   browser (petugas)          browser (layar antrian)
        |                              |
        +--------------+---------------+
                       |
                       v
              +------------------+
              |    Supabase      |
              |  database + API  |
              +------------------+
```

## Alur data

Browser membaca dan menulis data antrian lewat klien Supabase. Tiap periode menyimpan antriannya sendiri, jadi petugas membuka periode yang sedang aktif dan memperbaruinya dari satu layar.

## Keputusan Desain

**Supabase, bukan server sendiri.** Untuk alat internal kecil, backend terpisah menambah beban operasional tanpa manfaat. Supabase menghilangkan kebutuhan itu dan membuat deploy tetap sederhana.

**Frontend memegang seluruh aplikasi.** Data layer dikelola, jadi aplikasi cukup berupa build statis.

## Perlu dilengkapi

Bagian berikut belum ada datanya dan akan diisi setelah dokumentasi proyek dibuat:

- Skema tabel: periode, antrian, nomor, status
- Row Level Security dan aturan akses
- Mekanisme update layar antrian: realtime subscription atau polling
- Definisi status dan transisi (menunggu, dipanggil, selesai, lewat)
- Penanganan nomor yang tidak hadir (no-show)
- Reset dan penutupan periode
